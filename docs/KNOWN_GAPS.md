# Known gaps

Things that are impossible (or not yet possible) in a browser, or deliberately not replicated, with the closest
alternative we implement instead (CLAUDE.md §4 "When you are unsure").

| Area                             | Gap                                                                                                                                                                           | Alternative / status                                                                                                                |
| -------------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ----------------------------------------------------------------------------------------------------------------------------------- |
| 3D                               | The reference app removed its 3D feature set; we do not implement 3D.                                                                                                         | None — out of scope (PLAN B14).                                                                                                     |
| Filter plugins                   | Native binary filter plugins (8BF) cannot run in a browser.                                                                                                                   | Our own sandboxed plugin API (PLAN B19).                                                                                            |
| Cloud services                   | Vendor stock-photo, fonts, cloud documents, boards and social-portfolio services are not replicated.                                                                          | Local projects in OPFS, local asset library, open font sources only with owner approval (PLAN B24).                                 |
| Colour management (temporary)    | Until lcms2 lands (Phase 7), images are treated as sRGB and embedded ICC profiles are not applied.                                                                            | Planned for Phase 7.                                                                                                                |
| Scratch disk in private browsing | Browsers give private/incognito windows no Origin Private File System (confirmed for WebKit), so the scratch disk cannot start there.                                         | The app detects this and keeps all tiles in memory; the memory budget then only informs. Normal windows are unaffected.             |
| Documents larger than memory     | Only data no open document is using (undo history, snapshots) is moved to the scratch disk; the tiles of open documents always stay in memory so drawing never waits on disk. | Sufficient for Phase 0. Swapping live tiles of very large documents is planned with the large-document performance work (PLAN B25). |
| Indexed Color (temporary)        | Palette PNGs open as RGB(A) because Indexed Color mode is not implemented yet.                                                                                                | Indexed mode is planned for Phase 7.                                                                                                |
| CMYK JPEG (temporary)            | CMYK/YCCK JPEG files are refused with a message, since showing them correctly needs CMYK colour management.                                                                   | Planned for Phase 7 (lcms2).                                                                                                        |
| Save formats (temporary)         | Phase 0 saves PNG only, with default options (no options dialog yet).                                                                                                         | Remaining formats and options arrive with PLAN B3/B22.                                                                              |
| Cmd + Space on macOS             | macOS reserves Cmd + Space for Spotlight, so the browser never receives it and the temporary Zoom shortcut cannot work there unless the user changes Spotlight's shortcut.    | Use the Zoom tool (Z), Alt/Option + wheel, pinch, or Cmd + "+"/"−".                                                                 |
