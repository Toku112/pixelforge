# Phase 1 check with real Photoshop

Phase 1 ends with two quick checks that only a person with Photoshop can do. Each takes a few minutes.

## 1. Our file, opened in Photoshop

1. Open `composition.psd` (in this folder) in Photoshop.
2. It should look like `composition-expected.png` (also in this folder): a colourful checkerboard photo on a beige
   canvas, a darker blue-tinted rectangle over part of it, a soft pale-yellow ellipse at the top right, and a thick red
   stroke shaped like a roof.
3. The Layers panel should show, from top to bottom:
   - a group **Shapes** (blend mode Screen, opacity 70%), open, containing:
     - **Hidden** — eye turned off (a black layer)
     - **Circle** — the soft yellow ellipse, slightly turned
   - **Square** — blend mode Multiply, Opacity 60%, Fill 80%, with the position lock on
   - **Paint** — the red stroke
   - **Background** — locked, as usual
4. Tell me anything that looks or is named differently (a screenshot helps).

## 2. A Photoshop file, opened in PixelForge

1. In Photoshop, make a small file with a few layers — for example: two or three pixel layers, a group, one layer in a
   blend mode such as Multiply, one at a lower opacity, one hidden. Keep it simple: no text, effects or masks yet
   (those come in later phases, and PixelForge will say it simplified them).
2. Save it as PSD (leave "Maximize Compatibility" on).
3. Open it in PixelForge with File > Open, and compare the picture and the Layers panel with Photoshop.
4. Tell me what differs, or send me the file.
