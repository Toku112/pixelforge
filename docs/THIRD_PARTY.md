# Third-party components

Every dependency, ML model, bundled OCIO config, LUT, ICC profile and font must be listed here with its licence
(CLAUDE.md §1.2). The `check-licenses` build target (`cmake/scripts/check_licenses.cmake`) checks every installed
vcpkg port against the policy below (`cmake/LicensePolicy.cmake`) and against the generated table in this file.

**Licence policy (D-064)**

- Allowed by default: MIT, BSD-2/3-Clause, Apache-2.0, ISC, Zlib, BSL-1.0, MPL-2.0 (as a separate module), CC0-1.0
  and 0BSD (public-domain style, D-071).
- LGPL: dynamically linked only, owner-approved components only — Qt 6 and an LGPL build of FFmpeg.
- Anything else (GPL, AGPL, non-commercial, unknown) requires the owner's approval first, including build tools whose
  output ships.

The browser prototype's npm and Rust dependencies are listed on the branch `archive/web-prototype`.

## Added components

### vcpkg ports

Generated from vcpkg's records of each installed port (its declared SPDX licence and version) by
`cmake --build --preset <preset> --target update-third-party`; `check-licenses` fails when a row is missing or out
of date. Rows for ports installed only on some platforms stay in the table (e.g. `sse2neon` exists only on Arm);
remove a row by hand when a port is dropped. "Ships = no" means build or test use only. The package target copies
each shipped port's licence text into the app (`ThirdPartyLicenses/`).

Why each one is there: OpenEXR (EXR files; brings OpenJPH for HTJ2K, libdeflate, zstd), Imath (half floats,
vectors, matrices), OpenColorIO (scene colour management; brings expat, minizip-ng, pystring, yaml-cpp, zlib, and
sse2neon on Arm), oneTBB (task scheduler; built without its optional hwloc feature), GoogleTest (tests only).
Where a port offers a choice of licences (`A OR B`), we use it under the allowed one — e.g. zstd under BSD-3-Clause.
